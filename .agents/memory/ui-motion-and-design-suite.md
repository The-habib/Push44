# UI Motion & Design Suite Plugin

## Summary
Installed top internet-recommended UI animation and motion design skills into `.agents/plugins/ui-motion-and-design-suite/`.

## Bundled Skills
1. **`gsap-framer-scroll-animation`**: Scroll-driven motion, ScrollTrigger, `useScroll`, `useTransform`, pinning, parallax, horizontal scrubbing.
2. **`premium-frontend-ui`**: Award-level frontend craftsmanship, entry sequences, hero typography architecture, fluid navigation.
3. **`motion-craft-microinteractions`**: Emil Kowalski & Apple UI craft standards, spring physics tokens, layoutId shared element morphing, magnetic buttons.
4. **`web-design-reviewer`**: Automated UI/UX auditing, accessibility contrast, responsive breakpoint validation.
5. **`threejs-webgl-motion`**: 3D background canvases, interactive shader gradients, particle systems, GPU memory management.
