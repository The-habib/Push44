# Awesome Design Skills Plugin

## Summary
Installed 60+ UI/UX design systems and style skills from [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills).

## Structure
- Plugin manifest: `.agents/plugins/awesome-design-skills/plugin.json`
- Design rules: `.agents/plugins/awesome-design-skills/rules/AGENTS.md`
- Skills catalog: `.agents/plugins/awesome-design-skills/skills/` and `.agents/skills/`

## Included Skill Categories
- **Aesthetic Systems**: `minimal`, `skeumorphism`, `glassmorphism`, `neumorphism`, `neobrutalism`, `claymorphism`, `retro`, `paper`, `material`, `dithered`, `riso`, `vintage`, `terracotta`, `neon`.
- **Layout & Structure**: `bento`, `spacious`, `square`, `tetris`, `clean`, `geometric`, `sleek`, `stitch`.
- **Domain Specializations**: `enterprise`, `corporate`, `shadcn`, `editorial`, `storytelling`, `creative`, `agentic`, `contemporary`.
