Base44 FAQ

Does Push44 remove the badge on live *.base44.app sites?
Yes! Push44 injects CSS blocker rules into your app's stylesheet and triggers a production deploy, removing the badge for all visitors.
Does Push44 work with all Base44 projects?
Yes. Push44 uses the Base44 API to read and deploy any project associated with your account.
Do I need a paid Base44 plan?
No. The Base44 API and deployment endpoints used by Push44 are available to all account tiers.
How long does a Base44 export take?
Typically under 30 seconds for most projects.
Can I export multiple Base44 projects?
Yes. Run Push44 separately for each project, pointing to different GitHub repos.
Is my Base44 API token safe in Push44?
Yes. It's stored in your browser's localStorage and never sent to any Push44 server.
