Rocket.new FAQ

Does Push44 include backend code in Rocket.new exports?
Yes. The full container filesystem is exported, including all backend, frontend, and configuration files.
How do I build an Android APK with Push44?
Connect your Rocket.new project in Push44, navigate to the APK section, and click 'Build APK'. Push44 triggers the build and monitors progress.
What if my Rocket.new container is sleeping?
Open your project in Rocket.new to wake the container, then return to Push44 and retry.
